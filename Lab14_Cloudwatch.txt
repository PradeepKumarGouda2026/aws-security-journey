# **LAB 73: CLOUDWATCH INSIGHTS - THREAT HUNTING**

## **Lab 73.1: Query Failed API Calls**

```
CloudWatch Console → Logs → Insights

Select log groups:
└─ ✅ CloudTrail/security-audit-trail

Time range: Last 1 hour (or custom)

Query 1: Find all failed API calls
```

```sql
fields @timestamp, userIdentity.userName, eventName, sourceIPAddress, errorCode, errorMessage
| filter errorCode like /Unauthorized|AccessDenied|Denied/
| sort @timestamp desc
| limit 50
```

```
Run query

Results show:
├─ Timestamp: When it happened
├─ User: Who tried
├─ Event: What they tried to do
├─ IP: Where from
├─ Error: Why it failed
└─ Message: Details

Example result:
@timestamp: 2026-03-03 16:45:23.000
userName: bob
eventName: DeleteBucket
sourceIPAddress: 203.0.113.99
errorCode: AccessDenied
errorMessage: User is not authorized to perform: s3:DeleteBucket

✅ Found unauthorized attempts!
```

## **Lab 73.4: Query S3 Access Patterns**

## **Lab 73.6: Advanced Query - Failed Logins by User**

```
Query 6: Count failed logins per user
```

```sql
fields userIdentity.userName as User
| filter eventName = "ConsoleLogin" 
| filter errorMessage = "Failed authentication"
| stats count() as FailedAttempts by User
| sort FailedAttempts desc
```

```
Run query

Results:
User: bob, FailedAttempts: 47
User: test-user, FailedAttempts: 23
User: alice, FailedAttempts: 3

Analysis:
├─ bob: 47 failed attempts → Investigate! 🚨
│   └─ Password forgotten? Brute force?
├─ test-user: 23 attempts → Check if account needed
├─ alice: 3 attempts → Normal (typos)

✅ Brute force detection complete!
```
