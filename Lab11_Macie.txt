LAB 57: CUSTOM DATA IDENTIFIERS 🎯
Now let's teach Macie to find YOUR company's specific sensitive data!

WHAT ARE CUSTOM DATA IDENTIFIERS?
Managed Identifiers (built-in):
├─ Credit cards ✅
├─ SSN ✅
├─ AWS keys ✅
└─ 100+ standard types ✅

But what about YOUR company's data?
├─ Employee IDs: EMP-12345
├─ Customer IDs: CUST-2024-98765
├─ Internal project codes: PROJ-ALPHA-001
├─ Custom account numbers: ACC-US-123456
└─ Proprietary format data

Custom Data Identifiers = Teach Macie YOUR patterns! 🎓

HOW CUSTOM IDENTIFIERS WORK:
You define:
1. Name: "Employee ID"
2. Description: "Internal employee identifier"
3. Pattern: Regular expression (regex)
   Example: EMP-[0-9]{5}
4. Keywords (optional): Words near the pattern
   Example: "employee", "staff", "personnel"
5. Ignore words (optional): False positive patterns

Macie then finds:
- EMP-12345 ✅
- EMP-98765 ✅
- employee EMP-55555 ✅
- EMP-ABCDE ❌ (doesn't match pattern)

LAB 57.4: CREATE CUSTOM IDENTIFIER VIA CLI
bash# CloudShell

# Create employee ID identifier
aws macie2 create-custom-data-identifier \\
  --name "Employee-ID-CLI" \\
  --description "Employee ID pattern via CLI" \\
  --regex "EMP-[0-9]{5}" \\
  --keywords "employee" "staff" "personnel" \\
  --maximum-match-distance 50 \\
  --severity-levels findingSeverityLevel=HIGH \\
  --tags DataType=EmployeeID,Source=CLI

# Create customer ID identifier
aws macie2 create-custom-data-identifier \\
  --name "Customer-ID-CLI" \\
  --description "Customer ID pattern via CLI" \\
  --regex "CUST-[0-9]{4}-[0-9]{5}" \\
  --keywords "customer" "client" \\
  --maximum-match-distance 50 \\
  --severity-levels findingSeverityLevel=MEDIUM

# List all custom identifiers
aws macie2 list-custom-data-identifiers

# Get specific identifier details
aws macie2 get-custom-data-identifier \\
  --id "CUSTOM_ID_FROM_LIST"

# **LAB 57.7: REGEX PATTERN EXAMPLES**

## **Common Custom Patterns:**

### **1. Internal Ticket IDs:**
```
Pattern: TICKET-[0-9]{8}
Matches: TICKET-12345678
Example: Support ticket IDs
```

### **2. Order Numbers:**
```
Pattern: ORD-[A-Z]{2}-[0-9]{6}
Matches: ORD-US-123456, ORD-EU-999999
Example: E-commerce order IDs
```

### **3. License Keys:**
```
Pattern: [A-Z0-9]{5}-[A-Z0-9]{5}-[A-Z0-9]{5}-[A-Z0-9]{5}
Matches: ABC12-DEF34-GHI56-JKL78
Example: Software license keys
```

### **4. Internal IP Ranges:**
```
Pattern: 10\\.20\\.(1[0-9]{2}|2[0-4][0-9]|25[0-5])\\.[0-9]{1,3}
Matches: 10.20.100.1 to 10.20.255.255
Example: Corporate network IPs
```
