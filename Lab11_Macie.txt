LAB 53: ENABLE MACIE
Lab 53.1: Enable Macie
AWS Console → Search "Macie" → Amazon Macie

First-time screen:

Click "Get started"

Review permissions:
├─ Macie needs to:
│   ├─ List all S3 buckets
│   ├─ Read bucket metadata
│   ├─ Read object content
│   └─ Create service-linked role
└─ All automatic!

Click "Enable Macie"

⏱️ Wait 10-20 seconds

✅ Macie is now enabled!

You'll see:
├─ Dashboard
├─ Summary statistics (initially 0)
├─ S3 buckets discovered
└─ Jobs (none yet)

Lab 53.2: Review Bucket Inventory
Macie Console → S3 buckets (left sidebar)

You'll see ALL your S3 buckets listed:

For each bucket, Macie shows:
├─ Bucket name
├─ Total objects
├─ Total size
├─ Public access status
├─ Encryption status
├─ Shared with other accounts
├─ Versioning status
└─ Tags

Example:
┌─────────────────────────────────────────────┐
│ Bucket: customer-uploads                    │
│ Objects: 1,247                              │
│ Size: 15.3 GB                               │
│ Public: NO ✅                               │
│ Encryption: SSE-S3 ✅                       │
│ Shared: NO ✅                               │
│ Region: us-east-1                           │
└─────────────────────────────────────────────┘

Click on any bucket to see detailed statistics

✅ Macie has inventoried all your buckets!

This inventory is FREE and happens automatically.

Lab 53.3: Enable via CLI
bash# CloudShell

# Enable Macie
aws macie2 enable-macie

# Get Macie status
aws macie2 get-macie-session

# Output:
{
  "status": "ENABLED",
  "serviceRole": "arn:aws:iam::...",
  "findingPublishingFrequency": "FIFTEEN_MINUTES",
  "createdAt": "2026-03-03T10:00:00Z"
}

# List S3 buckets tracked by Macie
aws macie2 describe-buckets --max-results 10

✅ Macie enabled via CLI!

```
# **LAB 55: RUN DISCOVERY JOB**

## **Lab 55.1: Create Discovery Job (Console)**
```
Macie Console → Jobs (left sidebar)

Click "Create job"

Step 1: Review S3 buckets

Select buckets to scan:
└─ ✅ Check your test bucket (macie-test-bucket-...)

You can also:
├─ Select all buckets
├─ Filter by tag
├─ Filter by name pattern
└─ Exclude specific buckets

For now: Just select your test bucket

Click "Next"

Step 2: Refine the scope

Sampling depth:
└─ ● All objects (scan everything) ← Select this

Include existing objects:
└─ ✅ Yes (scan existing files)

Object criteria (optional):
├─ File extensions: (leave empty = all files)
├─ Last modified: (leave empty = all dates)
└─ Size: (leave empty = all sizes)

Click "Next"

Step 3: Select managed data identifiers

These are the types of sensitive data to find:

✅ All (recommended - finds everything)

Or manually select:
├─ Credentials
├─ Credit card numbers
├─ Driver's license numbers
├─ Financial information
├─ Health insurance IDs
├─ National identification numbers
├─ Passport numbers
├─ Phone numbers
├─ Social Security numbers
└─ And many more...

For this lab: Keep "All" selected ✅

Custom data identifiers:
└─ None (we'll create one later)

Click "Next"

Step 4: Enter general settings

Job name: test-bucket-discovery-job

Job description: Finding sensitive data in test bucket

Job type:
├─ ○ One-time job ← Select this (runs once)
└─ ○ Scheduled job (runs regularly)

For production, scheduled jobs are useful!

Click "Next"

Step 5: Review and create

Review settings:
├─ Buckets: 1 (your test bucket)
├─ Objects: ~5
├─ Identifiers: All managed identifiers
└─ Type: One-time job

Estimated cost: ~$0.01 (very cheap for test!)

Click "Submit"

✅ Job created and started!

Job status: Running ⏳

└─ Cost: $0.000001 (negligible)

Lab 55.3: Create Job via CLI
bash# CloudShell

# Create discovery job
aws macie2 create-classification-job \
  --job-type ONE_TIME \
  --name "test-bucket-cli-job" \
  --s3-job-definition "{
    \"bucketDefinitions\": [{
      \"accountId\": \"$(aws sts get-caller-identity --query Account --output text)\",
      \"buckets\": [\"$BUCKET_NAME\"]
    }]
  }"

# Get job ID from output
JOB_ID="..." # Copy from output

# Check job status
aws macie2 describe-classification-job --job-id $JOB_ID

# List all jobs
aws macie2 list-classification-jobs

✅ Job created via CLI!
