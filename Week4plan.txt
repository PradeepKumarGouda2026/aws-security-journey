Amazon GuardDuty = AI-powered threat detection

What it does:
🤖 Analyzes CloudTrail, VPC Flow Logs, DNS logs
🤖 Uses machine learning to detect threats
🤖 Finds: Compromised instances, reconnaissance,
   credential theft, cryptocurrency mining, data exfiltration

Findings types:
├─ Backdoor (compromised EC2)
├─ Behavior (unusual API calls)
├─ CryptoCurrency (Bitcoin mining)
├─ PenTest (Kali Linux detected)
├─ Policy (IAM unusual behavior)
├─ PrivilegeEscalation (attacker gaining access)
├─ Recon (port scanning, network probing)
├─ ResourceConsumption (unusual usage)
├─ Stealth (hiding tracks)
├─ Trojan (malware detected)
└─ UnauthorizedAccess (stolen credentials)

Best part: NO agents, NO infrastructure, AUTOMATIC!
