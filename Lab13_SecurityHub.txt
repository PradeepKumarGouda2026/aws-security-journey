## **Lab 67.3: Create Auto-Remediation Lambda**

```
Lambda Console → Create function

Name: SecurityHub-AutoRemediate

Runtime: Python 3.12

Role: Create new role with basic permissions

Create function

Add permissions to role:
├─ AmazonEC2FullAccess (for EC2 actions)
├─ AmazonS3FullAccess (for S3 actions)
└─ AWSSecurityHubFullAccess (to update findings)

Code:
```

```python
import json
import boto3

ec2 = boto3.client('ec2')
s3 = boto3.client('s3')
securityhub = boto3.client('securityhub')

def lambda_handler(event, context):
    """
    Auto-remediate Security Hub findings
    """
    
    print("Received Security Hub finding:")
    print(json.dumps(event, indent=2))
    
    # Extract finding details
    finding = event['detail']['findings'][0]
    
    finding_id = finding['Id']
    product_arn = finding['ProductArn']
    severity = finding['Severity']['Label']
    title = finding['Title']
    resource_type = finding['Resources'][0]['Type']
    resource_id = finding['Resources'][0]['Id']
    
    print(f"Finding: {title}")
    print(f"Severity: {severity}")
    print(f"Resource: {resource_type} - {resource_id}")
    
    # Auto-remediation logic
    remediated = False
    action_taken = "No automated remediation available"
    
    try:
        # Remediate S3 bucket public access
        if "S3 Block Public Access" in title and resource_type == "AwsS3Bucket":
            bucket_name = resource_id.split(":")[-1]
            
            # Enable Block Public Access
            s3.put_public_access_block(
                Bucket=bucket_name,
                PublicAccessBlockConfiguration={
                    'BlockPublicAcls': True,
                    'IgnorePublicAcls': True,
                    'BlockPublicPolicy': True,
                    'RestrictPublicBuckets': True
                }
            )
            
            remediated = True
            action_taken = f"Enabled Block Public Access on bucket {bucket_name}"
            print(f"✅ {action_taken}")
        
        # Remediate unencrypted EBS volume
        elif "EBS volumes should be encrypted" in title and resource_type == "AwsEc2Volume":
            volume_id = resource_id.split("/")[-1]
            
            # Note: Cannot encrypt existing volume directly
            # Create snapshot and notify for manual encryption
            snapshot = ec2.create_snapshot(
                VolumeId=volume_id,
                Description=f"Snapshot for encryption - Security Hub finding {finding_id}"
            )
            
            remediated = False  # Manual step required
            action_taken = f"Created snapshot {snapshot['SnapshotId']} for encryption. Manual: copy with encryption, replace volume"
            print(f"⚠️ {action_taken}")
        
        # Remediate overly permissive security group
        elif "should not allow unrestricted access" in title and resource_type == "AwsEc2SecurityGroup":
            sg_id = resource_id.split("/")[-1]
            
            # This is complex - just notify, don't auto-fix
            # (could break applications)
            action_taken = f"Security group {sg_id} requires manual review - potential breaking change"
            print(f"⚠️ {action_taken}")
        
        # Update finding workflow status
        if remediated:
            securityhub.batch_update_findings(
                FindingIdentifiers=[
                    {
                        'Id': finding_id,
                        'ProductArn': product_arn
                    }
                ],
                Workflow={'Status': 'RESOLVED'},
                Note={
                    'Text': f'Auto-remediated: {action_taken}',
                    'UpdatedBy': 'AutoRemediationLambda'
                }
            )
            print(f"✅ Updated finding status to RESOLVED")
        
        return {
            'statusCode': 200,
            'body': json.dumps({
                'finding_id': finding_id,
                'remediated': remediated,
                'action': action_taken
            })
        }
        
    except Exception as e:
        error_msg = f"Error remediating finding: {str(e)}"
        print(f"❌ {error_msg}")
        
        # Update finding with error note
        securityhub.batch_update_findings(
            FindingIdentifiers=[
                {
                    'Id': finding_id,
                    'ProductArn': product_arn
                }
            ],
            Note={
                'Text': f'Auto-remediation failed: {str(e)}',
                'UpdatedBy': 'AutoRemediationLambda'
            }
        )
        
        return {
            'statusCode': 500,
            'body': json.dumps({'error': str(e)})
        }
```

```
Deploy

Configuration:
├─ Timeout: 60 seconds
└─ Memory: 512 MB

✅ Auto-remediation Lambda created!
```

## **Lab 68.1: Understanding Cross-Account Security Hub**

```
In Organizations with multiple AWS accounts:

Without aggregation:
├─ Account A: Security Hub findings
├─ Account B: Security Hub findings
├─ Account C: Security Hub findings
└─ Must check each account separately ❌

With aggregation:
├─ Master account: ALL findings from A, B, C
└─ Single pane of glass ✅

Setup:
1. Enable Security Hub in all accounts
2. Designate one account as "administrator"
3. Add member accounts
4. Findings aggregate to administrator account

Benefits:
✅ Centralized security view
✅ Organization-wide compliance
✅ Unified security score
✅ Cross-account correlation
```
