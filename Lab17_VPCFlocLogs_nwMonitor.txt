## **Lab 83.1: Create VPC for Flow Logs Testing**

```bash
# CloudShell

echo "=== Creating VPC for Flow Logs Lab ==="

# Create VPC
FLOW_VPC=$(aws ec2 create-vpc --cidr-block 10.2.0.0/16 --tag-specifications 'ResourceType=vpc,Tags=[{Key=Name,Value=FlowLogs-VPC}]' --query 'Vpc.VpcId' --output text)

aws ec2 modify-vpc-attribute --vpc-id $FLOW_VPC --enable-dns-hostnames

echo "FlowLogs VPC created: $FLOW_VPC"

# Create subnet
FLOW_SUBNET=$(aws ec2 create-subnet --vpc-id $FLOW_VPC --cidr-block 10.2.1.0/24 --availability-zone us-east-1a --tag-specifications 'ResourceType=subnet,Tags=[{Key=Name,Value=FlowLogs-Subnet}]' --query 'Subnet.SubnetId' --output text)

aws ec2 modify-subnet-attribute --subnet-id $FLOW_SUBNET --map-public-ip-on-launch

echo "Subnet created: $FLOW_SUBNET"

# Create and attach IGW
FLOW_IGW=$(aws ec2 create-internet-gateway --tag-specifications 'ResourceType=internet-gateway,Tags=[{Key=Name,Value=FlowLogs-IGW}]' --query 'InternetGateway.InternetGatewayId' --output text)

aws ec2 attach-internet-gateway --internet-gateway-id $FLOW_IGW --vpc-id $FLOW_VPC

echo "IGW attached: $FLOW_IGW"

# Create route table
FLOW_RT=$(aws ec2 create-route-table --vpc-id $FLOW_VPC --tag-specifications 'ResourceType=route-table,Tags=[{Key=Name,Value=FlowLogs-RT}]' --query 'RouteTable.RouteTableId' --output text)

aws ec2 create-route --route-table-id $FLOW_RT --destination-cidr-block 0.0.0.0/0 --gateway-id $FLOW_IGW

aws ec2 associate-route-table --route-table-id $FLOW_RT --subnet-id $FLOW_SUBNET

echo "✅ VPC infrastructure ready!"
```

## **Lab 84.1: Create Traffic Analysis Queries**

```bash
# CloudShell

cat > flow-logs-analysis-queries.md << 'EOF'
# VPC Flow Logs Analysis Queries

## Security Monitoring Queries

### 1. Detect Port Scanning Attempts
```
fields @timestamp, srcAddr, dstPort, action
| filter action = "REJECT"
| stats count(distinct dstPort) as ports_scanned, count(*) as total_attempts by srcAddr
| filter ports_scanned > 10
| sort total_attempts desc
```
**What to look for:** High number of unique ports from single IP
**Action:** Block source IP in NACL

### 2. Identify Brute Force Attacks (SSH/RDP)
```
fields @timestamp, srcAddr, dstAddr, dstPort, action
| filter (dstPort = 22 or dstPort = 3389) and action = "REJECT"
| stats count(*) as attempts by srcAddr, dstPort
| filter attempts > 20
| sort attempts desc
```
**What to look for:** Many failed attempts to SSH/RDP ports
**Action:** Block source IP, review auth logs

### 3. Find Data Exfiltration
```
fields @timestamp, srcAddr, dstAddr, bytes, protocol
| filter srcAddr like /^10\./
| stats sum(bytes) as totalBytes by srcAddr, dstAddr
| filter totalBytes > 100000000
| sort totalBytes desc
```
**What to look for:** Large data transfers to external IPs
**Action:** Investigate instance, check for compromise

### 4. Detect Unusual Outbound Connections
```
fields @timestamp, srcAddr, dstAddr, dstPort
| filter srcAddr like /^10\./ and not (dstAddr like /^10\./)
| stats count(*) as connections by srcAddr, dstPort
| filter dstPort not in [80, 443]
| sort connections desc
```
**What to look for:** Internal instances connecting on unusual ports
**Action:** Investigate application behavior

### 5. Monitor Database Access
```
fields @timestamp, srcAddr, dstAddr, dstPort, action
| filter dstPort in [3306, 5432, 1433, 27017]
| stats count(*) as queries by srcAddr, dstPort, action
| sort queries desc
```
**What to look for:** Database access from unexpected sources
**Action:** Verify security group rules

## Traffic Analysis Queries

### 6. Top Bandwidth Consumers
```
fields @timestamp, srcAddr, dstAddr, bytes
| stats sum(bytes) as totalBytes by srcAddr
| sort totalBytes desc
| limit 20
```
**Use:** Identify instances consuming most bandwidth
**Action:** Cost optimization, capacity planning

### 7. Traffic Distribution by Protocol
```
fields @timestamp, protocol
| stats count(*) as flows by protocol
| sort flows desc
```
**Use:** Understand protocol mix
**Protocols:** 6=TCP, 17=UDP, 1=ICMP

### 8. Peak Traffic Times
```
fields @timestamp, bytes
| stats sum(bytes) as totalBytes by bin(5m)
| sort @timestamp desc
```
**Use:** Identify traffic patterns over time
**Action:** Capacity planning

### 9. Internal vs External Traffic
```
fields @timestamp, srcAddr, dstAddr, bytes
| stats
    sum(bytes * (dstAddr like /^10\./)) as internalBytes,
    sum(bytes * (not (dstAddr like /^10\./))) as externalBytes
```
**Use:** Understand traffic distribution
**Action:** Cost optimization (NAT Gateway usage)

### 10. Connection Success Rate
```
fields @timestamp, action
| stats
    count(*) as total,
    sum(action = "ACCEPT") as accepted,
    sum(action = "REJECT") as rejected
```
**Use:** Measure network health
**Low accept rate:** Possible misconfiguration

## Compliance Queries

### 11. Access from Specific Regions/IPs
```
fields @timestamp, srcAddr, dstAddr, action
| filter srcAddr in ["198.51.100.0/24", "203.0.113.0/24"]
| stats count(*) as attempts by srcAddr, action
| sort attempts desc
```
**Use:** Monitor blocked regions
**Action:** Verify geo-blocking effectiveness

### 12. Encryption Verification (TLS/SSL)
```
fields @timestamp, srcAddr, dstPort
| filter dstPort in [443, 8443]
| stats count(*) as tlsConnections by srcAddr
| sort tlsConnections desc
```
**Use:** Verify encrypted traffic
**Compare:** Against port 80 (unencrypted)

### 13. After-Hours Access
```
fields @timestamp, srcAddr, dstAddr, dstPort
| filter hour(@timestamp) < 8 or hour(@timestamp) > 18
| filter weekday(@timestamp) in [6, 0]
| stats count(*) as connections by srcAddr
| sort connections desc
```
**Use:** Detect unusual access times
**Action:** Investigate off-hours activity

EOF

cat flow-logs-analysis-queries.md

echo "✅ Analysis queries saved!"
```

## **Lab 85.2: Create CloudWatch Alarms**

```bash
# CloudShell

echo "=== Creating CloudWatch Alarms for Security Events ==="

# Get SNS topic ARN (create if doesn't exist)
SNS_TOPIC_ARN=$(aws sns list-topics --query 'Topics[?contains(TopicArn, `SecurityAlerts`)].TopicArn' --output text)

if [ -z "$SNS_TOPIC_ARN" ]; then
    echo "Creating SNS topic..."
    SNS_TOPIC_ARN=$(aws sns create-topic --name SecurityAlerts --query 'TopicArn' --output text)
    
    # Subscribe your email
    echo "Enter your email for security alerts:"
    read USER_EMAIL
    aws sns subscribe --topic-arn $SNS_TOPIC_ARN --protocol email --notification-endpoint $USER_EMAIL
    
    echo "✅ SNS topic created. Check your email and confirm subscription!"
    echo "⏱️  Waiting 30 seconds for you to confirm..."
    sleep 30
fi

echo "Using SNS Topic: $SNS_TOPIC_ARN"

# Alarm 1: High Rate of Rejected Connections (Port Scan)
aws cloudwatch put-metric-alarm \
  --alarm-name VPC-PortScan-HighRate \
  --alarm-description "Detects possible port scanning - many rejected connections" \
  --metric-name RejectedConnections \
  --namespace VPCFlowLogs \
  --statistic Sum \
  --period 300 \
  --evaluation-periods 1 \
  --threshold 50 \
  --comparison-operator GreaterThanThreshold \
  --alarm-actions $SNS_TOPIC_ARN

echo "✅ Alarm 1: Port Scan Detection (>50 rejects in 5 min)"

# Alarm 2: SSH Brute Force
```
