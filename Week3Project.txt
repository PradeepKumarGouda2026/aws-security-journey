## **PROJECT IMPLEMENTATION:**

### **Step 1: Verify All Services Are Enabled**

```bash
# CloudShell - Quick verification

echo "=== Week 3 Services Status Check ==="
echo ""

# 1. CloudTrail
echo "1. CloudTrail:"
aws cloudtrail describe-trails --query 'trailList[*].[Name,IsMultiRegionTrail]' --output table
echo ""

# 2. GuardDuty
echo "2. GuardDuty:"
aws guardduty list-detectors --query 'DetectorIds[0]' --output text
if [ $? -eq 0 ]; then echo "✅ Enabled"; else echo "❌ Not enabled"; fi
echo ""

# 3. Macie (might be disabled to save cost)
echo "3. Macie:"
aws macie2 get-macie-session --query 'status' --output text 2>/dev/null
if [ $? -eq 0 ]; then echo "✅ Enabled"; else echo "❌ Not enabled (OK - expensive)"; fi
echo ""

# 4. Inspector
echo "4. Inspector:"
aws inspector2 get-configuration --query 'state' --output text 2>/dev/null
if [ $? -eq 0 ]; then echo "✅ Enabled"; else echo "❌ Not enabled"; fi
echo ""

# 5. Security Hub
echo "5. Security Hub:"
aws securityhub describe-hub --query 'HubArn' --output text 2>/dev/null
if [ $? -eq 0 ]; then echo "✅ Enabled"; else echo "❌ Not enabled"; fi
echo ""

# 6. CloudWatch (always available)
echo "6. CloudWatch: ✅ Always available"
echo ""

echo "=== Check Complete ==="
```

### **Step 2: Build Integration Test Scenario**

We'll simulate a security incident and watch all services detect and respond!

#### **Create Test Resources:**

```bash
# CloudShell

echo "Creating test environment for incident simulation..."

# 1. Create test S3 bucket (will be target of attack)
BUCKET_NAME="security-test-$(aws sts get-caller-identity --query Account --output text)-$(date +%s)"
aws s3 mb s3://$BUCKET_NAME
echo "Created bucket: $BUCKET_NAME"

# 2. Upload sensitive test file
cat > sensitive-data.txt << 'EOF'
Customer Database Export
SSN: 123-45-6789
Credit Card: 4111-1111-1111-1111
AWS Access Key: AKIAIOSFODNN7EXAMPLE
EOF

aws s3 cp sensitive-data.txt s3://$BUCKET_NAME/
echo "Uploaded sensitive test file"

# 3. Create test IAM user (will be "compromised")
aws iam create-user --user-name test-compromised-user 2>/dev/null
echo "Created test IAM user"

# 4. Create access key for test user
KEY_OUTPUT=$(aws iam create-access-key --user-name test-compromised-user --output json)
ACCESS_KEY=$(echo $KEY_OUTPUT | jq -r '.AccessKey.AccessKeyId')
SECRET_KEY=$(echo $KEY_OUTPUT | jq -r '.AccessKey.SecretAccessKey')
echo "Created access keys for test user"

echo ""
echo "=== Test Environment Ready ==="
echo "Bucket: $BUCKET_NAME"
echo "Test user: test-compromised-user"
echo ""
```

### **Step 3: Simulate Security Incidents**

#### **Incident 1: Unauthorized API Calls**

```bash
# CloudShell

echo "=== Simulating Incident 1: Unauthorized Access Attempts ==="

# Attempt to access bucket without permissions (will fail)
for i in {1..10}; do
  aws s3 ls s3://$BUCKET_NAME --profile nonexistent-profile 2>/dev/null
  echo "Attempt $i: Unauthorized access (expected to fail)"
  sleep 1
done

echo ""
echo "✅ Generated 10 unauthorized API calls"
echo "Expected detections:"
echo "  - CloudTrail: Logged all attempts"
echo "  - CloudWatch: Metric filter should increment"
echo "  - GuardDuty: May detect unusual pattern"
echo ""
```

---

#### **Incident 2: Suspicious Actions**

```bash
# CloudShell

echo "=== Simulating Incident 2: Suspicious Security Group Changes ==="

# Create and modify security group (suspicious pattern)
SG_ID=$(aws ec2 create-security-group --group-name test-suspicious-sg --description "Test security group" --query 'GroupId' --output text)

# Open to internet (bad practice - will trigger alerts)
aws ec2 authorize-security-group-ingress --group-id $SG_ID --protocol tcp --port 22 --cidr 0.0.0.0/0
aws ec2 authorize-security-group-ingress --group-id $SG_ID --protocol tcp --port 3389 --cidr 0.0.0.0/0
aws ec2 authorize-security-group-ingress --group-id $SG_ID --protocol tcp --port 1433 --cidr 0.0.0.0/0

echo ""
echo "✅ Created security group with overly permissive rules"
echo "Expected detections:"
echo "  - CloudTrail: Logged all changes"
echo "  - CloudWatch: SecurityGroupChanges metric incremented"
echo "  - Security Hub: Compliance finding (0.0.0.0/0 not allowed)"
echo "  - Config: Rule violation"
echo ""
```

#### **Incident 3: Sensitive Data Exposure**

```bash
# CloudShell

echo "=== Simulating Incident 3: Public Bucket (Data Exposure) ==="

# Disable Block Public Access (will trigger Security Hub)
```

### **Step 4: Monitor Detection Across All Services**

```bash
# CloudShell

echo "=== Waiting 2 minutes for events to propagate ==="
sleep 120

echo ""
echo "=== Checking Detections Across Services ==="
echo ""

# CloudTrail - Recent events
echo "1. CLOUDTRAIL - Recent Security Events:"
aws cloudtrail lookup-events --lookup-attributes AttributeKey=EventName,AttributeValue=PutPublicAccessBlock --max-results 3 --query 'Events[*].[EventTime,EventName,Username]' --output table
echo ""

# GuardDuty - Findings (may take longer)
echo "2. GUARDDUTY - Active Findings:"
DETECTOR_ID=$(aws guardduty list-detectors --query 'DetectorIds[0]' --output text)
if [ "$DETECTOR_ID" != "None" ]; then
  aws guardduty list-findings --detector-id $DETECTOR_ID --max-results 5
  echo "(Note: Real findings may take 15-30 minutes to appear)"
else
  echo "GuardDuty not enabled"
fi
echo ""

# Security Hub - Recent findings
echo "3. SECURITY HUB - Recent Findings:"
aws securityhub get-findings --filters '{"RecordState":[{"Value":"ACTIVE","Comparison":"EQUALS"}],"SeverityLabel":[{"Value":"HIGH","Comparison":"EQUALS"},{"Value":"CRITICAL","Comparison":"EQUALS"}]}' --max-results 5 --query 'Findings[*].[Title,ProductName,Severity.Label]' --output table 2>/dev/null
echo ""

# CloudWatch - Metrics
echo "4. CLOUDWATCH - Security Metrics (Last Hour):"
aws cloudwatch get-metric-statistics --namespace SecurityMetrics --metric-name SecurityGroupChanges --start-time $(date -u -d '1 hour ago' +%Y-%m-%dT%H:%M:%S) --end-time $(date -u +%Y-%m-%dT%H:%M:%S) --period 3600 --statistics Sum --query 'Datapoints[*].[Timestamp,Sum]' --output table 2>/dev/null
echo ""

echo "=== Detection Check Complete ==="
echo ""
echo "Full propagation timeline:"
echo "  - CloudTrail: Immediate (within seconds)"
echo "  - CloudWatch Metrics: 1-5 minutes"
echo "  - GuardDuty: 15-30 minutes for new findings"
echo "  - Security Hub: 5-15 minutes"
echo "  - Inspector: Runs on schedule (every 24h for EC2)"
echo ""
```
