# **DAY 15: CLOUDTRAIL DEEP DIVE**

## **What is CloudTrail?**

```
CloudTrail = Complete history of AWS API calls

Every action in AWS:
- Who: Which user/role
- What: Which API call
- When: Exact timestamp
- Where: Source IP, region
- Result: Success or failure
- Details: Request parameters

Examples:
- alice created S3 bucket "sensitive-data" at 2:34 PM
- bob deleted EC2 instance i-abc123 from 203.0.113.5
- Lambda function accessed Secrets Manager at 3:15 AM
- Root user logged in without MFA ⚠️
```
