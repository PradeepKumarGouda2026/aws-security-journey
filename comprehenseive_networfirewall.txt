## **THEORY: AWS NETWORK FIREWALL**

### **Core Concepts:**

```
AWS Network Firewall = Managed stateful network firewall

Key Features:
├─ Layer 3-7 filtering
├─ Stateful + Stateless rules
├─ Deep packet inspection
├─ Domain filtering (block facebook.com)
├─ IDS/IPS (Suricata rules)
├─ TLS inspection
├─ Centralized management
└─ Auto-scaling, HA

Positioning:
Internet ←→ IGW ←→ Network Firewall ←→ Your VPC

Cost: ~$577/month (2 AZs) + $0.065/GB
```

---

## **ARCHITECTURE:**

```
┌─────────────────────────────────────────┐
│  VPC with Network Firewall             │
│                                         │
│  Firewall Subnet (10.0.1.0/24)        │
│  ┌──────────────────────────┐         │
│  │ Network Firewall         │         │
│  │ Endpoint (AZ-1)          │         │
│  └──────────┬───────────────┘         │
│             ↓ Inspects all traffic    │
│  ┌──────────────────────────┐         │
│  │ Protected Subnet         │         │
│  │ (10.0.2.0/24)           │         │
│  │                          │         │
│  │ ┌────────┐  ┌─────────┐│         │
│  │ │Web Tier│  │App Tier ││         │
│  │ └────────┘  └─────────┘│         │
│  └──────────────────────────┘         │
└─────────────────────────────────────────┘
```

---

## **RULE TYPES:**

```
1. STATELESS RULES (Fast, packet-level)
   - Evaluated FIRST
   - No connection tracking
   - Actions: PASS, DROP, FORWARD

2. STATEFUL RULES (Advanced, connection-aware)

   A) Standard 5-tuple rules
      Source IP/Port, Dest IP/Port, Protocol

   B) Domain filtering
      Block: *.facebook.com, *.gambling.com
      Allow: *.amazonaws.com

   C) Suricata rules (IDS/IPS)
      alert http any any -> any any
      (msg:"SQL Injection"; content:"UNION SELECT";)

3. AWS MANAGED RULE GROUPS
   - Threat Intelligence
   - Malware domains
   - Bot networks
```

## **LAB 88: DEPLOY NETWORK FIREWALL**

### **Step 1: Create VPC Infrastructure**

```bash
# CloudShell

echo "=== Creating Network Firewall VPC ==="

# Create VPC
NFW_VPC=$(aws ec2 create-vpc --cidr-block 10.3.0.0/16 --tag-specifications 'ResourceType=vpc,Tags=[{Key=Name,Value=NetworkFirewall-VPC}]' --query 'Vpc.VpcId' --output text)

aws ec2 modify-vpc-attribute --vpc-id $NFW_VPC --enable-dns-hostnames

echo "VPC created: $NFW_VPC"

# Create Firewall Subnet (where firewall endpoint lives)
NFW_FIREWALL_SUBNET=$(aws ec2 create-subnet --vpc-id $NFW_VPC --cidr-block 10.3.1.0/24 --availability-zone us-east-1a --tag-specifications 'ResourceType=subnet,Tags=[{Key=Name,Value=Firewall-Subnet}]' --query 'Subnet.SubnetId' --output text)

echo "Firewall subnet: $NFW_FIREWALL_SUBNET"

# Create Protected Subnet (your workloads)
NFW_PROTECTED_SUBNET=$(aws ec2 create-subnet --vpc-id $NFW_VPC --cidr-block 10.3.2.0/24 --availability-zone us-east-1a --tag-specifications 'ResourceType=subnet,Tags=[{Key=Name,Value=Protected-Subnet}]' --query 'Subnet.SubnetId' --output text)

aws ec2 modify-subnet-attribute --subnet-id $NFW_PROTECTED_SUBNET --map-public-ip-on-launch

echo "Protected subnet: $NFW_PROTECTED_SUBNET"

# Create IGW
NFW_IGW=$(aws ec2 create-internet-gateway --tag-specifications 'ResourceType=internet-gateway,Tags=[{Key=Name,Value=NFW-IGW}]' --query 'InternetGateway.InternetGatewayId' --output text)

aws ec2 attach-internet-gateway --internet-gateway-id $NFW_IGW --vpc-id $NFW_VPC

echo "IGW attached: $NFW_IGW"

echo "✅ VPC infrastructure ready!"
```

### **Step 5: Deploy Network Firewall**

```bash
# CloudShell

echo "=== Deploying Network Firewall ==="

NFW_FIREWALL=$(aws network-firewall create-firewall \
  --firewall-name ProductionFirewall \
  --firewall-policy-arn $NFW_POLICY_ARN \
  --vpc-id $NFW_VPC \
  --subnet-mappings SubnetId=$NFW_FIREWALL_SUBNET \
  --query 'Firewall.FirewallArn' \
  --output text)

echo "Network Firewall created: $NFW_FIREWALL"

# Wait for firewall to be ready
echo "⏱️  Waiting for firewall to become active (3-5 minutes)..."

while true; do
    STATUS=$(aws network-firewall describe-firewall --firewall-arn $NFW_FIREWALL --query 'FirewallStatus.Status' --output text)
    if [ "$STATUS" == "READY" ]; then
        echo "✅ Network Firewall is READY!"
        break
    fi
    echo "  Status: $STATUS (waiting...)"
    sleep 30
done

# Get firewall endpoint ID
NFW_ENDPOINT_ID=$(aws network-firewall describe-firewall --firewall-arn $NFW_FIREWALL --query 'FirewallStatus.SyncStates.*.Attachment.EndpointId' --output text | head -1)

echo "Firewall Endpoint: $NFW_ENDPOINT_ID"
```

### **Step 6: Configure Routing Through Firewall**

```bash
# CloudShell

echo "=== Configuring Routes ==="

# Create route table for IGW (routes to firewall)
NFW_IGW_RT=$(aws ec2 create-route-table --vpc-id $NFW_VPC --tag-specifications 'ResourceType=route-table,Tags=[{Key=Name,Value=IGW-RT}]' --query 'RouteTable.RouteTableId' --output text)

# Route protected subnet traffic through firewall endpoint
aws ec2 create-route --route-table-id $NFW_IGW_RT --destination-cidr-block 10.3.2.0/24 --vpc-endpoint-id $NFW_ENDPOINT_ID

echo "✅ IGW routes to firewall endpoint"

# Create route table for protected subnet
NFW_PROTECTED_RT=$(aws ec2 create-route-table --vpc-id $NFW_VPC --tag-specifications 'ResourceType=route-table,Tags=[{Key=Name,Value=Protected-RT}]' --query 'RouteTable.RouteTableId' --output text)

# Route internet traffic through firewall endpoint
aws ec2 create-route --route-table-id $NFW_PROTECTED_RT --destination-cidr-block 0.0.0.0/0 --vpc-endpoint-id $NFW_ENDPOINT_ID

# Associate with protected subnet
aws ec2 associate-route-table --route-table-id $NFW_PROTECTED_RT --subnet-id $NFW_PROTECTED_SUBNET

echo "✅ Protected subnet routes through firewall"

# Create route table for firewall subnet (to IGW)
NFW_FIREWALL_RT=$(aws ec2 create-route-table --vpc-id $NFW_VPC --tag-specifications 'ResourceType=route-table,Tags=[{Key=Name,Value=Firewall-RT}]' --query 'RouteTable.RouteTableId' --output text)

aws ec2 create-route --route-table-id $NFW_FIREWALL_RT --destination-cidr-block 0.0.0.0/0 --gateway-id $NFW_IGW

aws ec2 associate-route-table --route-table-id $NFW_FIREWALL_RT --subnet-id $NFW_FIREWALL_SUBNET

echo "✅ Firewall subnet routes to IGW"

echo ""
echo "Traffic Flow:"
echo "Internet → IGW → Firewall Endpoint → Protected Subnet → Firewall → IGW → Internet"
```

## **THEORY: AWS WAF (Web Application Firewall)**

### **Core Concepts:**

```
AWS WAF = Web Application Firewall (Layer 7)

Protects:
├─ CloudFront distributions
├─ Application Load Balancer (ALB)
├─ API Gateway
├─ AppSync GraphQL
└─ AWS Verified Access

Defends against:
├─ SQL injection
├─ Cross-site scripting (XSS)
├─ Geo-blocking
├─ Rate limiting (DDoS mitigation)
├─ Bot traffic
├─ IP reputation
└─ Custom attack patterns

Cost: $5/month per Web ACL + $1/rule + $0.60/million requests
```

---

## **WAF COMPONENTS:**

```
1. WEB ACL (Access Control List)
   └─ Container for rules
      Applied to resources (ALB, CloudFront)
      Default action: ALLOW or BLOCK

2. RULES
   └─ Match conditions + action
      Actions: ALLOW, BLOCK, COUNT, CAPTCHA
      Priority-based evaluation

3. RULE GROUPS
   └─ Collection of rules
      Reusable across Web ACLs
      AWS Managed or Custom

4. IP SETS
   └─ Lists of IP addresses/ranges
      Block or allow specific IPs
      Up to 10,000 IPs per set

5. REGEX PATTERN SETS
   └─ Regular expressions
      Match complex patterns
      SQL injection, XSS detection
```

---

## **AWS MANAGED RULE GROUPS:**

```
AWS provides pre-built rule groups:

1. Core Rule Set (CRS)
   ├─ OWASP Top 10 protection
   ├─ SQL injection
   ├─ XSS
   └─ Common vulnerabilities

2. Admin Protection
   └─ Blocks access to admin pages
      (/admin, /phpmyadmin, etc.)

3. Known Bad Inputs
   └─ Known attack patterns
      CVE exploits

4. SQL Database
   └─ SQL injection protection
      Advanced patterns

5. Linux/Windows Operating System
   └─ OS-specific attacks
      Command injection

6. PHP/WordPress
   └─ CMS-specific protection

7. IP Reputation
   └─ Known malicious IPs
      Updated by AWS

8. Anonymous IP
   └─ Block Tor, VPN, proxies
      Prevent anonymous access

9. Bot Control
   └─ Managed bot detection
      Allow good bots (Google, Bing)
      Block bad bots

Cost: FREE to ~$10/month per rule group
```

---

## **RATE-BASED RULES:**

```
Protect against DDoS and brute force:

Rate limiting:
├─ Requests per 5-minute window
├─ Per IP address
├─ Automatic blocking
└─ Configurable threshold

Example:
If IP sends >2000 requests in 5 min:
└─ Block for 10 minutes (configurable)

Use cases:
├─ Login page protection (100 req/5min)
├─ API rate limiting (1000 req/5min)
├─ Search/expensive operations (500 req/5min)
└─ DDoS mitigation (10000 req/5min)
```
